# 5개 융합기술 트랙 교과목 아코디언 — 설계

- 날짜: 2026-07-17
- 브랜치: feat/content-from-plan
- 관련 파일: `src/consts.ts`, `src/pages/program.astro`
- 출처: `탈플라스틱 홈페이지용 사업계획서.pdf` (45~49페이지 "전체 교과목 개설계획(총괄)")

## 목표

교육과정 페이지(`/program`)의 "5개 융합기술 트랙" 목록에서 각 트랙 항목을 클릭하면,
해당 트랙의 교과목 리스트가 인라인(아코디언)으로 펼쳐지도록 한다. 교과목 데이터는
사업계획서 편성표를 그대로 반영한다.

## 데이터 모델 (`src/consts.ts`)

`Track` 타입에 `courses` 필드 추가.

```ts
export type Course = {
  name: string;      // 교과목명 ("(필수)"/"(주요)" 표기는 제거)
  type: '전필' | '전선';
  credits: number | null; // 학점, 미표기 시 null → "-" 표시
  period: string;    // 개설시기 (예: "매년 1학기", "1,3,5차년도 2학기")
  desc: string;      // 교육내용
};
export type CourseGroup = { group: string; courses: Course[] };
// group ∈ '전공기초' | '전공심화Ⅰ' | '전공심화Ⅱ' | '실무'
export type Track = { no; title; univ; desc; courses: CourseGroup[] };
```

- 공통 전공기초 2과목(폐플라스틱 재활용 및 자원화 기술 / 탈플라스틱 전과정 이해)과
  실무 캡스톤(산학연계 캡스톤 프로젝트)은 사업계획서 원문과 동일하게 모든 트랙에 반복 수록.
- 캡스톤 학점은 45페이지(재료·대체소재 트랙) 기준 3학점으로 전 트랙 통일(원문 일부 표는 "-"로 표기).
- `응용화학세미나`는 원문에 학점 미표기 → `credits: null`.
- 교과목명의 `(필수)`/`(주요)` 부기는 제거하고, 필수/선택 구분은 `전필`/`전선` 배지로 표현.

트랙별 교과목 구성(요약):
1. **재료·대체소재(중앙대)** — 기초 2 · 심화Ⅰ 5 · 심화Ⅱ 4 · 캡스톤 1
2. **재활용·자원화 공정(중앙대)** — 기초 2 · 심화Ⅰ 3 · 심화Ⅱ 7 · 캡스톤 1
3. **정책·순환시스템(금오공대)** — 기초 2 · 심화Ⅰ 2 · 심화Ⅱ 6 · 실무 2(LCA + 캡스톤)
4. **스마트 순환기술(중앙대)** — 기초 2 · 심화Ⅰ 4 · 심화Ⅱ 6 · 캡스톤 1
5. **융합형 탈플라스틱(금오공대)** — 기초 2 · 심화Ⅰ 2 · 심화Ⅱ 11 · 실무 2(응용화학세미나 + 캡스톤)

## UI (`src/pages/program.astro`)

- 각 `track-row`를 아코디언으로 변경:
  - 헤더는 `<button class="tr-head" aria-expanded aria-controls>` (키보드·스크린리더 접근성).
  - 헤더 우측에 펼침 표시 아이콘(▾, 펼침 시 회전).
  - 클릭 시 헤더 바로 아래 패널(`.tr-panel`)이 인라인으로 펼쳐짐.
- 패널 내부: 그룹별(전공기초/전공심화Ⅰ/전공심화Ⅱ/실무) 소제목 + 교과목 카드/행 목록.
  - 각 교과목: 이름 · 구분 배지(전필/전선) · 학점 · 개설시기 · 교육내용 설명.
- 기본은 전부 접힘. 여러 트랙 동시 펼침 허용.
- 기존 디자인 토큰(`--surface`, `--eco-500` 등), `reveal` 등장 애니메이션 유지.

## 동작 (`<script>`)

- `.tr-head` 클릭 → 대응 패널 토글, `aria-expanded` 갱신, 화살표 회전.
- 높이 전환은 `max-height`(CSS transition) 또는 `hidden` 토글 + grid-rows 트릭 중 단순한 방식 사용.
- 기존 IntersectionObserver reveal 로직과 공존.
