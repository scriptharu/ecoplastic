# 교과목 페이지 접속기록 → 구글시트 연동 (최초 1회)

`/courses`(개설 교과목) 페이지에서 학생이 **학교·학번·이름**을 입력하면, 입력 시각과 함께 구글 스프레드시트에 한 줄씩 쌓입니다. 이 문서는 그 시트와 수신용 스크립트를 만드는 절차입니다.

> 이 입력은 **인증이 아니라 이용 기록 수집**입니다. 교과목 목록 자체는 페이지 소스에 포함되어 있어 폼을 우회하려면 우회할 수 있습니다. "누가 언제 들어왔는지" 파악하는 용도로 쓰세요.

## 1. 스프레드시트 만들기

1. [Google 스프레드시트](https://sheets.google.com)에서 새 문서 생성 (예: `탈플라스틱 교과목 접속기록`).
2. 첫 행에 헤더를 입력합니다.

   | A | B | C | D |
   |---|---|---|---|
   | 기록시각 | 학교 | 학번 | 이름 |

## 2. Apps Script 작성

1. 스프레드시트 상단 메뉴 → **확장 프로그램 → Apps Script**.
2. 기본으로 열린 `Code.gs` 내용을 모두 지우고 아래를 붙여넣습니다.

```javascript
// 교과목 페이지 접속기록 수신 — POST된 JSON을 현재 시트에 한 줄 추가
function doPost(e) {
  try {
    var data = JSON.parse(e.postData.contents);

    // 필수값이 비어 있으면 기록하지 않는다
    if (!data.univ || !data.studentId || !data.name) {
      return json({ ok: false, error: 'missing field' });
    }

    var sheet = SpreadsheetApp.getActiveSpreadsheet().getSheets()[0];
    sheet.appendRow([
      new Date(),                        // 서버 시각 — 기기 시계에 좌우되지 않는다
      String(data.univ).slice(0, 50),
      String(data.studentId).slice(0, 20),
      String(data.name).slice(0, 30),
    ]);

    return json({ ok: true });
  } catch (err) {
    return json({ ok: false, error: String(err) });
  }
}

function json(obj) {
  return ContentService
    .createTextOutput(JSON.stringify(obj))
    .setMimeType(ContentService.MimeType.JSON);
}
```

3. 저장(💾).

## 3. 웹앱으로 배포

1. 우측 상단 **배포 → 새 배포**.
2. 톱니바퀴 → **웹 앱** 선택.
3. 설정:
   - **다음 사용자 인증 정보로 실행**: `나`
   - **액세스 권한이 있는 사용자**: `모든 사용자`  ← 반드시 이 값이어야 학생 브라우저에서 전송됩니다.
4. **배포** → 권한 승인 (본인 Google 계정으로 승인, "안전하지 않음" 경고가 뜨면 `고급 → 이동`).
5. 표시되는 **웹 앱 URL**을 복사합니다. `https://script.google.com/macros/s/.../exec` 형태입니다.

## 4. 사이트에 URL 연결

`src/consts.ts` 상단의 값을 복사한 URL로 채웁니다.

```ts
export const COURSE_LOG_ENDPOINT = 'https://script.google.com/macros/s/.../exec';
```

커밋 → push 하면 GitHub Actions가 자동 배포합니다.

> 이 값이 빈 문자열이면 기록 없이 폼이 그대로 통과합니다. 배포 전에도 페이지는 정상 동작하니, 급할 때는 비워둔 채로 두어도 됩니다.

## 5. 확인

1. 배포된 사이트에서 헤더 **e-class** 클릭 → `/courses` 진입.
2. 학교 선택 + 학번 + 이름 입력 → **교과목 목록 보기**.
3. 스프레드시트에 새 행이 추가되었는지 확인.

기록이 남지 않으면 아래를 순서대로 점검하세요.

- 3단계의 **액세스 권한이 있는 사용자**가 `모든 사용자`인지
- `COURSE_LOG_ENDPOINT`가 `/exec`로 끝나는지 (`/dev`는 본인만 접근 가능해서 실패합니다)
- 브라우저 개발자도구 → Network 탭에서 요청이 나가는지

## 6. 스크립트를 수정했을 때

Apps Script 코드를 고친 뒤에는 **배포 → 배포 관리 → 연필 아이콘 → 버전: 새 버전 → 배포**를 해야 반영됩니다. 저장만으로는 웹앱에 적용되지 않습니다. 이때 URL은 그대로 유지되므로 `consts.ts`는 고칠 필요가 없습니다.

## 참고 — 개인정보

현재 폼에는 수집·이용 동의 절차가 없습니다. 담당 부서에서 동의 절차를 요구하면 `src/pages/courses.astro`의 폼에 안내문과 동의 체크박스를 추가하면 됩니다. 시트에 쌓인 학번·이름은 개인정보이므로 열람 권한을 담당자로 제한하고, 보유 목적이 끝나면 삭제하는 편이 좋습니다.
