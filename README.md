# 중앙대학교 포스트 플라스틱 허브

Astro + Sveltia CMS 기반 정적 콘텐츠 사이트. GitHub Pages 무료 호스팅, DB·회원가입 없음, 관리자만 웹에서 콘텐츠 등록.

## 개발
```
npm install
npm run dev      # 로컬 개발 서버
npm run build    # 정적 빌드 → dist/
npm test         # 유닛 테스트
```
